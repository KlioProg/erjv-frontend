# ERJVPOS UI guidelines reference

The authoritative standard is [docs/UI_CONSISTENCY.md](docs/UI_CONSISTENCY.md). Read it and the relevant shared components before frontend UI work.

The canonical document contains:

- Authority, UX Honeycomb, BASIC, and Lean UX governance (section 1).
- Management-page composition and reusable page, table, form, dialog, and footer patterns (sections 2–3).
- Current implementation values, semantic tokens, spacing/proximity, component families, and unresolved owner decisions (section 4).
- Search, tables, pagination, logistics, Work → Wait → Resume, and specialized dashboard/report layouts (sections 5–9).
- Accessibility, business integrity, validation, and exceptions (sections 10–13).

This file defines no separate sizes, colors, fonts, or component rules. Valid guidance from the former guide is consolidated there; inaccurate implementation claims and historical proposals are identified explicitly. The `#6A994E` / `#80B918` conflict and visual approval of the current 22px title and compact table baseline remain documented decisions, not silent runtime changes.
