# ERJVPOS spacing reference

Use [docs/UI_CONSISTENCY.md](docs/UI_CONSISTENCY.md), the authoritative UI standard:

- Section 4.3 defines the 4px-based layout scale, proximity/grouping, shell insets, borders, radii, elevation, and legitimate measurement exceptions.
- Sections 4.2 and 6 record actual component and compact table sizes pending visual approval.
- Sections 3, 10, and 13 cover reusable composition, responsive accessibility, and justified exceptions.

The former guide's valid spacing and proximity guidance is consolidated there. Its 56/64px table-row and other prescriptive size proposals are not the current implementation baseline. Do not copy an independent scale from this file or change shared components solely to match those historical proposals.
